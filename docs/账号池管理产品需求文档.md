## 一、需求背景

### 1.1 业务背景

为提高算力资源利用率，平台计划在学生上课期间开放算力资源供教学使用。这需要解决以下问题：
- 批量创建和管理临时教学账号
- 课程结束后快速回收和清理账号资源
- 账号状态灵活控制（可用/禁用）

### 1.2 目标用户

| 用户角色 | 使用场景 |
|----------|----------|
| 平台管理员 | 管理账号池、调整池子大小、批量操作账号 |
| 授课教师 | 申请批量账号、绑定学生名单 |

### 1.3 核心价值

1. **资源高效利用**：课堂时间充分利用闲置算力资源
2. **管理效率提升**：批量操作替代人工逐个处理
3. **账号生命周期管理**：从创建、分配到回收的完整闭环

## 三、功能模块详细设计

### 3.1 账号池管理模块

#### 3.1.1 功能概述

管理一个独立的账号池，与平台手动注册的正式账号有明显区分。支持动态调整池子大小，账号状态管理。

#### 3.1.2 账号类型定义

| 账号类型 | 说明 | 标记方式 |
|----------|------|----------|
| 正式账号 | 手动注册的个人账号 | `account_type = 'official'` |
| 池子账号 | 系统自动创建的临时账号 | `account_type = 'pool'` |

#### 3.1.3 账号状态定义

| 状态 | 说明 | 权限 |
|------|------|------|
| 访客 | 账号禁用，无法使用算力 | 仅可登录，不可提交作业 |
| 超算 | 账号正常，可使用算力 | 完整算力使用权限 |

#### 3.1.4 页面功能设计

**页面布局**

```
┌─────────────────────────────────────────────────────────────┐
│ 账号池管理                                                    │
├─────────────────────────────────────────────────────────────┤
│ 池子大小设置: [ 50 ] [调整]  当前: 访客30 | 超算20 | 总计50   │
├─────────────────────────────────────────────────────────────┤
│ 标签筛选: [全部 ▼]  状态筛选: [全部 ▼]  [查询]               │
│                                                             │
│ [批量下线] [批量删除] [导出]                                 │
├─────────────────────────────────────────────────────────────┤
│ □ | 账号名   | 密码   | 状态  | 标签      | 分配对象 | 操作  │
│───┼──────────┼────────┼───────┼───────────┼──────────┼──────│
│ □ | pool_001 | ***** | 访客  | 2025春-C++| -        | [删除]│
│ □ | pool_002 | ***** | 超算  | 2025春-C++| 张三     | [下线]│
│ □ | pool_003 | ***** | 超算  | 2025春-AI | 李四     | [下线]│
└─────────────────────────────────────────────────────────────┘
```

**功能点详细说明**

| 功能 | 说明 | 规则 |
|------|------|------|
| 池子大小调整 | 输入目标数量，系统自动调整 | 当前数量 < 目标：批量创建访客账号<br>当前数量 > 目标：删除多余的访客账号（超算状态不可删除） |
| 批量下线 | 将超算状态账号改为访客状态 | 同时删除该账号下的所有作业 |
| 批量删除 | 删除选中的账号 | 仅可删除访客状态账号；删除时同步删除该账号的所有作业 |
| 标签管理 | 支持按标签批量查询、操作 | 标签格式：学期-课程名，如"2025春-C++" |

#### 3.1.5 账号命名规则

- 格式：`pool_{序号}`
- 序号从001开始，自动递增
- 示例：`pool_001`, `pool_002`, `pool_003`

#### 3.1.6 密码生成规则

- 初始密码：随机生成8位字母数字组合
- 密码在数据库中加密存储
- 页面显示时可选择显示/隐藏

支持教师通过Excel上传学生名单，系统自动从账号池分配访客账号给学生，并将账号状态改为超算。

#### 3.2.4 分配流程

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│ 上传Excel│ -> │ 解析名单 │ -> │ 检查库存 │ -> │ 分配账号 │
└─────────┘    └─────────┘    └─────────┘    └─────────┘
                                                  │
                    ┌─────────────────────────────┘
                    ▼
              ┌─────────┐    ┌─────────┐    ┌─────────┐
              │ 更新状态│ -> │ 记录日志│ -> │ 返回结果│
              │ 访客->超算    └─────────┘    └─────────┘
```

#### 3.2.5 校验规则

| 校验项 | 规则 | 错误提示 |
|--------|------|----------|
| 文件格式 | 必须为.xlsx或.xls | "请上传Excel文件(.xlsx或.xls)" |
| 名单非空 | 至少包含1个学生 | "学生名单不能为空" |
| 账号库存 | 访客账号数量 >= 学生数量 | "账号池访客账号不足，当前可用{count}个，需要{need}个，请先扩充账号池" |
| 标签格式 | 建议格式：学期-课程名 | 警告提示，不阻断 |

#### 3.2.6 分配结果

分配成功后，系统返回：
- 分配成功列表：学生姓名、分配账号、初始密码
- 支持导出分配结果Excel，方便教师分发给学生

## 四、数据库设计

### 4.1 账号池表 (t_account_pool)

```sql
CREATE TABLE t_account_pool (
    id INT(11) NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    username VARCHAR(255) NOT NULL DEFAULT '' COMMENT '账号名称',
    password VARCHAR(255) NOT NULL DEFAULT '' COMMENT '密码(加密存储)',
    account_type VARCHAR(50) NOT NULL DEFAULT 'pool' COMMENT '账号类型: official-正式, pool-池子',
    status VARCHAR(50) NOT NULL DEFAULT '访客' COMMENT '状态: 访客-禁用, 超算-正常',
    tag VARCHAR(255) DEFAULT NULL COMMENT '标签，如: 2025春-C++',
    assigned_to VARCHAR(255) DEFAULT NULL COMMENT '分配对象(学生姓名)',
    assigned_at TIMESTAMP NULL DEFAULT NULL COMMENT '分配时间',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (id),
    UNIQUE KEY uk_username (username),
    INDEX idx_status (status),
    INDEX idx_tag (tag),
    INDEX idx_account_type (account_type)
) COMMENT='账号池表';
```

### 4.2 账号分配记录表 (t_account_assignment_log)

```sql
CREATE TABLE t_account_assignment_log (
    id INT(11) NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    batch_no VARCHAR(64) NOT NULL DEFAULT '' COMMENT '批次号',
    tag VARCHAR(255) NOT NULL DEFAULT '' COMMENT '标签',
    student_name VARCHAR(255) NOT NULL DEFAULT '' COMMENT '学生姓名',
    username VARCHAR(255) NOT NULL DEFAULT '' COMMENT '分配的账号',
    assigned_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '分配时间',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (id),
    INDEX idx_batch_no (batch_no),
    INDEX idx_tag (tag),
    INDEX idx_username (username)
) COMMENT='账号分配记录表';
```

### 4.3 账号池操作日志表 (t_account_pool_operation_log)

```sql
CREATE TABLE t_account_pool_operation_log (
    id INT(11) NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    operation_type VARCHAR(50) NOT NULL DEFAULT '' COMMENT '操作类型: CREATE-创建, DELETE-删除, DISABLE-下线, ASSIGN-分配',
    username VARCHAR(255) DEFAULT NULL COMMENT '操作的账号',
    operator VARCHAR(255) NOT NULL DEFAULT '' COMMENT '操作人',
    detail TEXT COMMENT '操作详情(JSON格式)',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (id),
    INDEX idx_operation_type (operation_type),
    INDEX idx_created_at (created_at)
) COMMENT='账号池操作日志表';
```

## 七、安全与权限设计

### 7.1 权限控制

| 功能 | 管理员 | 教师 |
|------|--------|------|
| 调整账号池大小 | ✓ | ✗ |
| 批量下线/删除账号 | ✓ | ✗ |
| 查看账号池列表 | ✓ | ✗ |
| 批量分配账号 | ✓ | ✓ |
| 导出分配结果 | ✓ | ✓ |

### 7.2 安全策略

1. **密码安全**
   - 初始密码随机生成，包含大小写字母和数字
   - 密码加密存储（建议使用bcrypt）
   - 首次登录强制修改密码

2. **操作审计**
   - 所有批量操作记录日志
   - 日志保留180天

3. **数据隔离**
   - 池子账号与正式账号数据隔离
   - 作业数据随账号删除而清理

## 八、异常处理

### 8.1 常见异常场景

| 场景 | 处理方式 |
|------|----------|
| 账号池扩容时系统异常 | 已创建的账号保留，记录错误日志，返回部分成功结果 |
| 分配过程中账号库存不足 | 事务回滚，已分配的账号恢复原状态 |
| 删除账号时关联作业清理失败 | 记录错误日志，账号标记为待清理，定时任务重试 |
| Excel解析失败 | 返回具体错误行号和原因 |

### 8.2 错误码定义

| 错误码 | 说明 |
|--------|------|
| 400001 | 账号池大小参数无效 |
| 400002 | Excel文件格式错误 |
| 400003 | 学生名单为空 |
| 400004 | 账号库存不足 |
| 400005 | 存在超算状态账号，无法删除 |
| 500001 | 系统内部错误 |

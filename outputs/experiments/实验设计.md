我来设计一套实验方案，验证该专利的核心价值（自适应阈值消除人工调参、过渡期自动调整），同时客观评估其"自适应桶密度"能力的实际边界。

## 实验设计方案

### 实验一：自适应阈值消除人工调参验证

**目标**：验证同一组参数（α, Tmax, Tmin）能否适配不同纲量的监控指标，无需为每种指标单独调参。

#### 1.1 实验数据准备

生成 3 类典型监控指标的模拟数据（各 7 天，5 秒采样间隔）：

| 指标类型 | 值域范围 | 波动特征 | 数据生成模型 |
|---------|---------|---------|-------------|
| CPU 使用率 | 0-100% | 中等波动，周期性 | `50 + 20*sin(t/3600) + N(0, 10)` |
| 内存使用量 | 0-256 GB | 大波动，阶跃变化 | `128 + 随机游走(步长±20) + N(0, 5)` |
| 网络流量 | 0-10000 Mbps | 高波动，突发脉冲 | `5000 + 脉冲事件(随机触发) + N(0, 500)` |

#### 1.2 实验配置

```
统一参数（不随指标类型变化）：
- Tmax = 15000 秒
- Tmin = 60 秒  
- α = 0.25
- K = 20（直方图 bin 数）
- F_initial = 50（所有指标使用相同初始值）
- F_min = 5
```

#### 1.3 观测指标

| 观测项 | 说明 |
|-------|------|
| F 收敛曲线 | 记录每个闭合桶后的 F 值，观察收敛速度和稳定值 |
| 收敛后桶数 | 统计稳定期（后 50% 时间）的桶数量 |
| 条件1/条件2 触发比例 | 分析 Tmax 兜底机制的实际触发频率 |
| 降采样压缩比 | 原始数据条数 / 降采样结果条数 |

#### 1.4 预期结果与判定标准

| 判定项 | 通过标准 |
|-------|---------|
| 所有指标 F 均收敛 | 后 30% 桶的 F 变异系数 < 20% |
| 无需人工调参 | 统一参数在 3 类指标上均正常工作 |
| 收敛速度合理 | 5-15 个桶内达到稳定值的 90% |

### 实验二：过渡期自动调整能力验证

**目标**：验证当数据波动特征发生突变时，系统能否自动适应，无需人工重新调参。

#### 2.1 实验数据设计

设计**单条数据流**包含多个波动阶段：

```
时间轴（共 24 小时，5 秒采样）：
├─ 0-6h:   平稳期，波动幅度 ≈ 5
├─ 6-6.5h: 过渡期（渐变）
├─ 6.5-12h: 剧烈波动期，波动幅度 ≈ 50  
├─ 12-12.5h: 过渡期（渐变）
├─ 12.5-18h: 平稳期，波动幅度 ≈ 5
├─ 18-18.5h: 过渡期（渐变）
└─ 18.5-24h: 中等波动期，波动幅度 ≈ 25
```

#### 2.2 观测指标

| 观测项 | 说明 |
|-------|------|
| F 动态响应曲线 | 观察 F 随波动变化的跟踪能力 |
| 过渡期桶密度变化 | 统计各阶段的平均桶宽 |
| 响应延迟 | 波动突变后，F 达到新稳定值 90% 所需的桶数 |

#### 2.3 关键验证点

**验证"过渡期自动调整"**：
- 平稳→剧烈：初期 F 偏低，条件2易触发，桶加密；后期 F 追上，桶宽趋于 Tmax
- 剧烈→平稳：初期 F 偏高，条件2难触发，桶拉长（Tmax 兜底）；后期 F 下降

**验证"稳态后桶密度与波动无关"**：
- 对比三个稳定期（0-6h, 6.5-12h, 18.5-24h）的平均桶宽
- 预期：稳态后桶宽主要由 Tmax 决定，与波动幅度无显著相关性

### 实验三：自适应桶密度能力边界评估

**目标**：客观评估"波动剧烈处加密分桶"这一声称的实际有效性。

#### 3.1 对比实验设计

设计 3 种波动模式，对比专利方案 vs 固定阈值方案：

| 方案 | 阈值设置 |
|-----|---------|
| 专利方案（EWMA） | α=0.25, F_initial=50, 自适应 |
| 固定阈值（高） | F=50（始终不变） |
| 固定阈值（低） | F=10（始终不变） |

#### 3.2 测试场景

**场景 A：持续平稳（波动=5）**
- 预期：专利方案 F 收敛到 ~5，条件2几乎不触发，桶宽 ≈ Tmax

**场景 B：持续剧烈（波动=50）**
- 预期：专利方案 F 收敛到 ~50，条件2触发频率与场景 A 类似（稳态后）

**场景 C：周期性波动切换（每 2 小时切换 5↔50）**
- 预期：专利方案在每个切换初期表现出"自适应"，稳态后趋同

#### 3.3 关键度量

```
桶密度指数 = 总桶数 / 时间跨度

波动-桶密度相关性 = corr(滑动窗口内波动标准差, 滑动窗口内桶数)
```

**判定标准**：
- 若专利方案的"波动-桶密度相关性"显著高于固定阈值方案 → 自适应桶密度有效
- 若三者无显著差异 → 自适应桶密度效果有限（主要由 Tmax 决定）

### 实验四：分位数抗毛刺能力验证

**目标**：验证 P5/P95 分位数设计对 EWMA 稳定性的保护作用。

#### 4.1 实验设计

在平稳数据中注入不同频率的异常毛刺：

| 场景 | 毛刺频率 | 毛刺幅度 |
|-----|---------|---------|
| 无毛刺 | 0% | - |
| 低频毛刺 | 1% | 基准值的 10 倍 |
| 高频毛刺 | 5% | 基准值的 10 倍 |

对比两种波动幅度计算方式：
- **Raw Min/Max**：`bucket_range = max - min`
- **P5/P95 分位数**：`bucket_range = P95 - P5`（专利方案）

#### 4.2 观测指标

| 观测项 | 说明 |
|-------|------|
| F 稳定性 | F 序列的标准差 |
| 误切桶率 | 因毛刺导致的非预期切桶比例 |
| EWMA 收敛质量 | F 是否围绕真实波动水平稳定 |

### 实验五：端到端查询性能验证

**目标**：验证"写入即降采样，查询零计算"的实际效果。

#### 5.1 实验设置

- 数据规模：1000 万条原始记录（约 58 天，5 秒采样）
- 存储：MySQL 8.0 或 SQLite
- 查询场景：随机时间范围查询（跨度 1 小时 ~ 7 天）

#### 5.2 对比方案

| 方案 | 说明 |
|-----|------|
| 专利方案 | 写入时降采样，查询降采样结果 |
| 查询侧 LTTB | 每次查询实时扫描原始数据 |
| 固定窗口预聚合 | 写入时按固定 5 分钟窗口聚合 |

#### 5.3 性能指标

| 指标 | 测量方法 |
|-----|---------|
| 写入吞吐量 | 条/秒 |
| 查询延迟 | P50, P95, P99 响应时间 |
| 存储空间 | 原始数据 + 降采样结果的总大小 |
| 数据新鲜度 | 写入后到降采样结果可见的延迟 |
